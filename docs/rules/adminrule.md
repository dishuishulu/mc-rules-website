# 管理员相关守则

!!! warning "阅读提示"
    本文档适用于服务器全体管理员，同时也面向所有普通玩家阅读。
    管理员拥有服务器管理权限，但权力同时受到约束

## 管理员守则

 - 管理员不得利用权限给自己/其他人提供物品、破坏游戏公平
 - 处理玩家纠纷需要保持客观中立，禁止带私人情绪处罚玩家
 - 管理员行为同样需要接受玩家监督
 - 管理员可以拥有自己的服务器，但不能在此服务器内公开宣传

## 关于管理员职位
!!! important "重要声明"
    **本服务器不公开招收管理员**

管理员职位仅由服主主动进行挑选、邀请，不会接受玩家主动投递的申请。
无论在游戏内、Discord、QQ或者其他聊天渠道，**反复、持续请求、索要管理员权限的行为，属于骚扰行为，有可能被处以禁言处罚，请各位玩家知悉**

??? note "如果发现管理员违规怎么办"
    若你发现管理员存在滥用权限、违规操作，可联系服主进行反馈举报，服主将核实情况并做对应处理
