# 常用指令指南

## 传送类指令

| 指令 | 说明 |
| :--- | :--- |
| `/tpa [玩家名]` | 请求传送到他人身边 |
| `/tpahere [玩家名]` | 请求他人传送到你身边 |
| `/tpatoggle` | 禁用/启用传送到你身边 |
| `/tpacancel` | 取消自己发出去的传送请求 |
| `/tpatoggle [玩家名]` | 禁用/启用传送到特定玩家 |
| `/back` | 传送你到最后的位置 |

---

## 领地类指令

| 指令 | 说明 |
| :--- | :--- |
| `/res set [你的领地名]` | 设立领地（用木锄头以对角线的方式圈地） |
| `/res list` | 查看自己的所有领地 |
| `/res current` | 查看当前所在领地 |

---

## 家园类指令

| 指令 | 说明 |
| :--- | :--- |
| `/sethome [家名称]` | 将当前位置设为家 |
| `/delhome [家名称]` | 删除一个家 |

---

## 传送点类指令

| 指令 | 说明 |
| :--- | :--- |
| `/warp tp [地标名]` | 传送至指定的传送点 |
| `/warp create [地标名]` | 创建一个公共传送点 |
| `/warp delete [地标名]` | 删除一个公共传送点 |
| `/warp pcreate [地标名]` | 创建一个个人传送点 |
| `/warp pdelete [地标名]` | 删除一个个人传送点 |

---

## 经济类指令

| 指令 | 说明 |
| :--- | :--- |
| `/balance [玩家名]` | 查看自己的岛币数量(也可以直接计分板查看) |
| `/ecotop` | 查看服务器财富排行榜 |
| `/pay [玩家名] [金额]` | 转账给其他玩家 |
| `/shop` | 打开系统商店 |
| `/qs create [单价]` | 准星对准箱子/木桶, 手里拿着需要售卖的物品, 输入指令后创建自己的商店 |

---

## 其它指令

| 指令 | 说明 |
| :--- | :--- |
| `/sb` | 开启/关闭右侧计分板 |
| `/co i` | 开启/关闭侦查模式, 此模式下右键容器可查看拿取记录 |
