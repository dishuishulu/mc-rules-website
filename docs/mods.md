# DSMP 服务器可选客户端模组

!!! note "重要说明"
    以下模组**不是强制安装**。即使不安装，依旧可以正常进入服务器进行游玩
    但是不安装对应模组，将无法使用该模组提供的专属功能

## 需要安装的mod

*   **[Simple Voice Chat](https://modrinth.com/plugin/simple-voice-chat)**：提供游戏内空间位置语音聊天功能
    > 未安装：无法使用语音聊天、服务器内置音乐播放功能

*   **[Voice Messages](https://modrinth.com/plugin/voicemessages)**：Simple Voice Chat 的附属模组，可以在聊天框录制发送语音消息
    > 未安装：不能发送和接收游戏内语音消息

*   **[PatPat](https://modrinth.com/mod/patpat)**：趣味社交模组，可以蹲下抚摸其他玩家、生物的头部，播放动画与音效。
    > 未安装：无法抚摸其他玩家，也看不到别人的抚摸动画

## 安装提示
1. 点击上方模组名称，跳转至 Modrinth 下载页面；
2. 选择和服务器**游戏版本、加载器（Fabric / NeoForge）完全匹配**的版本，下载 `.jar` 文件；
3. 将 jar 文件放入客户端 `mods` 文件夹，启动游戏确认模组加载成功。
