# DSMP 服务器规则手册

[![Netlify Status](https://api.netlify.com/api/v1/badges/你的构建状态/deploy-status)](你的Netlify项目链接)

一个基于 **MkDocs** 和 **Material for MkDocs** 主题构建的 Minecraft 服务器规则文档站，旨在为玩家提供清晰、易读、可搜索的服务器指南。

## 📖 项目简介

本仓库是 **DSMP 服务器** 的官方规则手册，包含：

- **服务器介绍**：了解 DSMP 服务器的定位与愿景
- **完整规则体系**：涵盖游玩、建筑、养殖、交流及封禁等全面规范
- **决策流程**：清晰阐述服务器重大事务的民主决策机制
- **常用指令指南**：提供传送、领地、经济等实用指令速查表
- **暗色/亮色主题**：根据偏好自动切换，阅读舒适

## 🛠️ 技术栈

- **框架**：[MkDocs](https://www.mkdocs.org/)
- **主题**：[Material for MkDocs](https://squidfunk.github.io/mkdocs-material/)
- **部署**：[Netlify](https://www.netlify.com/)
- **版本控制**：[Git](https://git-scm.com/) + [GitHub](https://github.com/)
